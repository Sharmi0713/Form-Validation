# Form Validation System

## Project Description
A web-based form validation project developed using HTML, CSS, and JavaScript. It validates user inputs before form submission to ensure data accuracy and completeness.

## Features
- Name validation
- Email validation
- Password validation
- Required field checking
- Error message display
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the index.html file in a web browser.
3. Fill in the form fields.
4. Submit the form to test validation.

## Validation Rules
- Name should not be empty.
- Email should follow a valid format.
- Password should meet minimum length requirements.
- Required fields must be completed.

## Learning Outcomes
- JavaScript form validation
- DOM manipulation
- Event handling
- Front-end development basics
